# Shop Flowers

Shop Flowers es un e-commerce frontend de flores y arreglos florales pensado como pieza de portafolio profesional. El proyecto prioriza una experiencia de compra elegante, responsive y persistente usando datos locales, sin backend.

## Descripcion

Incluye home editorial, catalogo con busqueda y filtros en tiempo real, detalle de producto, carrito persistente, wishlist, checkout simulado, perfil con historial y tema oscuro. Toda la data vive en JSON y LocalStorage.

## Tecnologias

- React 19
- Vite
- React Router DOM
- Context API
- SCSS
- Framer Motion
- React Icons

## Deploy

El proyecto esta preparado para desplegarse en Netlify.

1. Conecta el repositorio en Netlify.
2. Usa `npm run build` como build command.
3. Publica la carpeta `dist`.
